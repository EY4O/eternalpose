Linemark

Bookmarks drawn like a transit map.

Collections become lines and branches, links become stations, and the network map shows where they meet. Full-text search, a broken-link checker and saved highlights. Local by default, with optional encrypted sync.

Voyage Tracker

One Piece in order, without spoilers.

Every arc, film and special on one roadmap, in the order to watch them, with your place saved as you go. Jump in at any episode, filter to canon or must-watch, and install it to use offline.

Model Librarian

Every model in its place.

In ComfyUI

A model manager built around a shared models folder. It finds and downloads whatever a workflow is missing, files models by base model, turns images into recipes and keeps the SSD for the models you use.

  • Comfy Registry
  • Source

On CivitAI, for Chrome and Edge

One click on a model page puts the best file for your GPU in the right ComfyUI folder, with the text encoder and VAE it needs.

  • Source

Gallery, for Windows

A fast gallery for every image and video you've generated. It reads the prompt, settings, models and workflow saved in each file, so you can search, rate and count them, and nothing leaves your PC.

  • Source

Free · Open source · ComfyUI custom nodes, a browser extension and a Windows app
