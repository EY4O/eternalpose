# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/JS on GitHub Pages, published from `docs/` (repository EY4O/eternalpose, custom domain eternalpose.io, HTTPS enforced), so design notes in the repository root are not served. No build step; self-hosted fonts.

## Users

Primarily people who already use one of Looneth's tools (arriving from Linemark's store listing, the One Piece Voyage Tracker, or a GitHub README) and want to see what else exists, or find support and contact. Secondarily, anyone judging Looneth's craft: collaborators, clients, or reviewers. Tools first, showcase second.

## Product Purpose

eternalpose.io is the personal project hub of Looneth (GitHub EY4O). It lists the projects that are ready to be seen, links each to its own home, and gives one place for support (Ko-fi) and contact. It is also the owned domain that Google's OAuth branding verification and the browser stores rely on, so it must read as a credible, maintained owner page.

## Positioning

One maker's small set of carefully made tools, each with its own subdomain or repository. The name comes from the Eternal Pose in One Piece, a compass that always points to one island; the hub points to whatever Looneth is building.

## Product Principles

1. Tools first: a visitor finds the project they came for, and where it lives, within seconds.
2. Show the work itself: real screenshots and real descriptions, never claims.
3. Small and maintained beats long and stale: only finished projects are listed.
4. The hub has its own personality, distinct from each project's identity.

## Accessibility & Inclusion

WCAG AA contrast, full keyboard use, prefers-reduced-motion honoured, and every project reachable without relying on scroll-driven effects.
