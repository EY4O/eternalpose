# Surface brief: eternalpose.io home

Mode: Persuade (project hub; tools first, craft showcase second). Built code-led (no image generation).

Audience and job: people who use one of Looneth's tools and want the others, support or contact; secondarily people judging craft. They must find their project and its link within seconds.

Content: Linemark, One Piece Voyage Tracker, Model Librarian suite (ComfyUI nodes + Chrome/Edge extension). Hidden for now: Prompto, ComfyUI-Prompto, Glass Dashboard, Bagcheck, RePlate, DanChro English Patch (listed in the repo README so they can come back).

References the user pinned: thedesignsociety.fr (retro-OS texture: scanlines, floating windows with [+], ticker, striped monogram; big editorial layout) and 2025.unseen.co (reactive ASCII eye hero, bracketed mono labels). User rejects: much One Piece imagery, gimmicks that slow finding a link, dark/techy looks, anything close to a plain list.

## Direction contract

THESIS: The compass is the page. A living ASCII eye watches the visitor and, when a project is chosen, its iris resolves into a compass whose needle points at that project. Refuses the category default of a heading over a grid of equal project cards.

OWN-WORLD: Cool grey ground (#E6E7EB) under faint scanlines, near-black ink, one international-orange needle accent. Anybody (variable width/weight) at extreme condensed weights for display, Departure Mono for window chrome and bracketed labels. Retro-OS windows: 1px ink frame, pinstriped title bar, close box, [+] that opens the project. ASCII rendered in Departure Mono glyphs spelling project names.

STORY: Visitor meets the eye, reads "Eternal Pose" and one line about Looneth, picks a project from the index window (the needle swings to it), scrolls through three editorial project spreads, each an animated ASCII hero window overlapped by a real-screenshot window, and ends at a striped EP monogram with GitHub, Ko-fi and email.

FIRST VIEWPORT: Full-bleed ASCII eye centred. "ETERNAL" giant top-left, "POSE" giant bottom-right. Top bar: wordmark left, "Projects by Looneth" centre, [GITHUB] [KO-FI] [EMAIL] [PAUSE MOTION] right. Intro line bottom-left. Projects window as a full-width strip of three columns along the bottom (user decision 2026-10-23, after trying a right-hand and a bottom-centre window), so the needle swings widely between projects; hovering or focusing one morphs eye to compass, needle points at it, glyphs spell its name. That index is the primary action.

FORM: user-pinned fusion of the two references (no concept-seed roll; pinned direction beats the roll). Signature interaction: eye-to-compass morph with needle targeting. Motion grammar: eased morph, pupil follows pointer, occasional blink, per-project ASCII loops only while visible; reduced motion renders still frames.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
