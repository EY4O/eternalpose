Eternal Pose

Tools, extensions and plugins by Looneth, mostly for keeping things in order: links, prompts, models, gear and a very long anime.

GitHubKo-fiiamlooneth@gmail.com

Apps and extensions

  • Linemark Chrome and Edge

    A bookmark manager drawn like a transit map. Lines and branches, full-text search and a broken-link checker; local by default, with optional encrypted sync.

  • One Piece Voyage Tracker Web app

    A spoiler-safe companion for watching all 1,120+ episodes and 15 films of One Piece in chronological order.

  • Prompto Chrome extension

    A side panel for catching, organising and remixing Stable Diffusion prompts, recipes and characters.

    Works with its ComfyUI nodes.

  • Glass Dashboard Local web app

    A local dashboard for whatever you track: GitHub repos, projects and goals, with pluggable adapters.

ComfyUI

  • Model Librarian ComfyUI nodes

    A model manager for Stability Matrix shared folders: missing-model downloads, a CivitAI library, recipes from images, dedupe and SSD/HDD storage tiers.

Final Fantasy XIV

  • Bagcheck Dalamud plugin

    A shopping list and retainer tracker for crafters.

  • RePlate Dalamud plugin

    Save and restore your adventurer plate and your gear sets' portraits.

    Both install from the plugin repository.

Games

  • DanChro English Patch Fan translation

    An unofficial English patch for the offline edition of DanMachi Battle Chronicle, with an optional fairer-gacha rebalance.
